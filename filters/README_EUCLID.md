# Euclid filter curves

The local filter files allow production jobs to run without network access:

- `Euclid_VIS.vis.dat`
- `Euclid_NISP.Y.dat`
- `Euclid_NISP.J.dat`
- `Euclid_NISP.H.dat`

The NISP Y/J/H curves were retrieved on 2026-11-04 through Synthesizer's SVO
filter interface using the identifiers `Euclid/NISP.Y`, `Euclid/NISP.J`, and
`Euclid/NISP.H`. Wavelengths are in Angstrom and the second column is the
dimensionless total transmission. The source service is the
[SVO Filter Profile Service](http://svo2.cab.inta-csic.es/theory/fps/).
